About SimScore Studio

SimScore Studio is a private desktop tool used only by the channel owner. It reads the public match schedule, renders simulation videos on the owner's own computer and uploads them to the owner's own YouTube channel as scheduled videos. It uses the YouTube Data API (YouTube API Services) solely for uploading and scheduling videos on that one channel. It is not offered to the public and has no other users.

Content

All visuals, sounds and music in the videos are created by code. No match footage, club crests or copyrighted music are used. SimScore is fan-made entertainment and is not affiliated with UEFA, any league or any club.
