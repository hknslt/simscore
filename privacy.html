Privacy Policy

Last updated: 14 October 2026

This policy explains how SimScore Studio (the "App"), a desktop tool operated by the owner of the SimScore YouTube channel, handles data. The App is used only by the channel owner to upload videos to their own YouTube channel. It has no other users and is not available to the public.

Use of YouTube API Services

The App uses the YouTube API Services (YouTube Data API v3). By using the App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the App accesses

  • YouTube channel basic information (channel ID, title, handle, thumbnail, subscriber count), read with the youtube.readonly scope, only to show which channel is connected.
  • Video uploads via the youtube.upload scope: the App uploads videos it has created, together with their title, description, tags and scheduled publish time, to the connected channel.
  • OAuth tokens issued by Google, which allow the App to upload on the owner's behalf.

The App does not access viewers' data, comments, watch history, or any other channel. It does not collect data from YouTube viewers.

How data is stored

All data is stored only on the owner's own computer in the App's data folder (OAuth token, channel name and the list of scheduled uploads). Nothing is sent to any server other than Google's APIs and the public football schedule and rating services the App reads (football-data.org, clubelo.com). No data is sold, shared with third parties or used for advertising.

How to revoke access and delete data

  • Access can be revoked at any time on the Google security settings page.
  • Using "Disconnect" in the App deletes the stored OAuth token immediately.
  • Deleting the App's data folder removes all stored data. Stored API data is deleted or refreshed at least every 30 days, as required by the YouTube API Services Developer Policies.

Cookies

This website and the App do not use cookies or tracking.
